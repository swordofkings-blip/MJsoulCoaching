■ 雀魂コーチングくん 導入マニュアル

このツールは、雀魂 (Mahjong Soul) の牌譜 (JSON 形式の対局ログ) を
ブラウザで 1 打ずつ再生したり、AI への「何切る」相談プロンプトを生成したりする
ローカルツールです。コーリングAIを内蔵しており、
各局面で AI の判断を確認できます。

■ 使い方

1. 牌譜ファイルを準備する
   - 牌譜は JSON 形式で `data/` フォルダに置きます
   - ファイル名は `record_*.json` または `record_*_trimmed.json` の形式
   - 一部のサンプル牌譜は `data/_exclude/` 内のサンプルを参照してください

2. 中継サーバーを起動
   - フォルダ内の「雀魂コーチングくん.exe」をダブルクリックで実行
   - 黒い画面 (コマンドプロンプト) が立ち上がり、
     「Starting server on port 8080...」と表示されれば成功です
   - 同時にブラウザが自動的に開き、牌譜一覧が表示されます
   - ※使用中は、この黒い画面を閉じないでください

3. 牌譜の再生と AI 相談
   - ブラウザに表示された牌譜一覧から見たい対局をクリック
   - シミュレーター画面で 1 打ずつ牌譜を再生できます
   - 任意の手番で「プロンプトをコピーする」ボタンを押すと、
     Gemini 等の AI チャットにそのまま貼り付けられる「何切る相談用プロンプト」がコピーされます

■ コーチングAI機能

「雀魂コーチングくん.exe」は麻雀 AI コアを内蔵しており、以下の機能を提供します:

- 牌選択: 各手番で最も合理的な打牌を選択
- 押しオリ判断: ベタオリ・押し・全ツッパを自動切替
- 役判定: 翻数・符数・役満をリアルタイム判定
- 人読み: 対戦者の癖 (副露率・和了率) を考慮した押し引き

■ 同梱物

- 雀魂コーチングくん.exe (約 7MB) - 麻雀 AI コア内蔵のサーバー
- _internal/ - Python ランタイム + ライブラリ
- README.txt - 本マニュアル
- data/ - サンプル牌譜 (※一部は _exclude フォルダ内)

■ 動作環境

- Windows 10 / 11 (64bit)
- ブラウザ: Chrome / Edge / Vivaldi 推奨
- ポート 8080 が空いていること

■ 終了方法

・「雀魂コーチングくん.exe」の黒い画面を閉じる
  (または、黒い画面内で Ctrl + C を押す) ことで終了します。

■ トラブルシューティング

Q. ブラウザが自動的に開かない
A. デフォルトのブラウザが設定されているか確認してください。
   手動で http://localhost:8080/ を開いてください。

Q. 牌譜一覧に何も表示されない
A. data/ フォルダに JSON 形式の牌譜があるか確認してください。
   ファイル名は record_*.json または record_*_trimmed.json の形式である必要があります。

Q. ポート 8080 が既に使われている
A. 他のアプリケーションがポート 8080 を使用していないか確認してください。
   別のポートを使用する場合は、雀魂コーチングくん.exe と同じフォルダに
   「port.txt」(例: 「8081」とだけ記載) を作成してください。

■ 牌譜データの入れ方

雀魂コーチングくんを開いた状態で、ブラウザで雀魂の調べたい牌譜を開くことで、ライブラリに追加されます。
