■ 雀魂 牌譜シミュレーター ＆ 検討ツール 導入マニュアル

このツールは、ブラウザ上の雀魂の対局をリアルタイムに記録し、後からブラウザで一打ずつの牌譜再生や、GeminiなどのAIへ「何切る」の相談をするためのプロンプトを生成できるローカルツールです。

--------------------------------------------------
■ 事前の準備（初回のみ）
--------------------------------------------------

1. Tampermonkeyのインストール（ブラウザ拡張機能）
   ご使用のブラウザに合わせて、以下のリンクからTampermonkey拡張機能を追加してください。
   ・Google Chrome版:
     https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=ja
   ・Microsoft Edge版:
     https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepknomcihgpkip

2. デベロッパーモードおよびユーザースクリプトの有効化
   ChromeやEdge、Vivaldiなどの最新仕様により、カスタムスクリプトを動かすために「デベロッパーモード」や「ユーザースクリプトの実行」をONにする必要があります。
   ・ブラウザのURL欄に以下を入力して拡張機能画面を開きます。
     chrome://extensions  （または vivaldi://extensions）
   ・画面右上にある「デベロッパーモード」のスイッチを「ON」にしてください。
   ※ブラウザによっては（Vivaldiなど）、さらに詳細項目に「ユーザースクリプトを許可する」というスイッチが表示されるため、こちらも「ON」にしてください。


--------------------------------------------------
■ 起動と使い方
--------------------------------------------------

1. 中継サーバーの起動
   ・フォルダ内にある「forwarder.exe」をダブルクリックで実行します。
   ・黒い画面（コマンドプロンプト）が立ち上がり、「Starting server on port 8080...」と表示されれば成功です。
   ※使用中は、この黒い画面を閉じないでください。

2. スクリプトの導入（初回または更新時のみ）
   ・ブラウザで以下のURLを開きます。
     http://localhost:8080/
   ・画面右上にある「🔧 Tampermonkey スクリプトを導入」ボタンをクリックします。
   ・Tampermonkeyのインストール画面が開くので、内容を確認して「インストール」または「更新」ボタンを押してください。
   ※導入後、初めて雀魂を開いた際に、Tampermonkeyから「外部への接続（127.0.0.1:8080）を許可しますか？」という警告ダイアログが表示される場合があります。その際は必ず「常に許可（Always allow）」を選択してください。


3. 対局データのキャプチャ（記録）
   ・ブラウザで通常通り雀魂（ https://game.mahjongsoul.com/ など）を開き、対局をプレイするか、あるいは「牌譜」から過去の対局を閲覧します。
   ・自動的に「forwarder.exe」がデータを検知し、裏で局のログをデコードして保存します。

4. 牌譜の再生とAI相談
   ・ブラウザで「 http://localhost:8080/ 」を再度開くと、保存された対局の一覧が表示されます。
   ・見たい対局をクリックすると、シミュレーター画面が立ち上がります。
   ・任意の手番で「プロンプトをコピーする」ボタンを押すと、Gemini等のAIチャットにそのまま貼り付けられる「何切る相談用プロンプト」がコピーされます。

--------------------------------------------------
■ 終了方法
--------------------------------------------------
・「forwarder.exe」の黒い画面を閉じる（または、黒い画面内で Ctrl + C を押す）ことで終了します。
